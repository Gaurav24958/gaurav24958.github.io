Executive Summary & Problem Statement

Applicants awaiting Irish visas through the New Delhi Visa Office (NDVO) faced a tedious daily ordeal: the embassy publishes decision lists as raw OpenDocument Spreadsheets (.ods files) containing thousands of rows of unstructured records. To check their status, applicants had to manually download heavy files, install compatible software, and sift through thousands of entries every single day.

Ireland Visa Decisions Tracker is an automated web utility built to eliminate this friction. It scrapes the Irish Embassy portal daily, downloads and parses the latest .ods file directly in memory using dynamic regex heuristics, and serves a modern, glassmorphic dashboard where applicants can check their visa outcome (Approved, Refused, or Pending) in seconds with their 8-digit application number.

Technical Architecture & Scraping Pipeline

Step 01 Cheerio & Axios

Automated Embassy Portal Crawling

Emulates desktop browser User-Agent headers to scrape the official Irish Embassy portal (Ireland.ie) daily, locating the newest _NDVO_Visa_Decisions.ods hyperlink while bypassing firewall blocks.

Why it matters: Completely eliminates the need for applicants to manually visit government pages and download raw files.
Step 02 Node.js Buffers

In-Memory Binary Streaming

Streams downloaded .ods spreadsheets straight into memory as binary buffers rather than saving intermediate files to disk.

Why it matters: Maximizes I/O throughput and prevents disk storage bloat on ephemeral cloud server containers.
Step 03 SheetJS (xlsx)

Dynamic Header Discovery (Regex)

Scans spreadsheet rows with regex patterns matching "Application Number" and "Decision" keys rather than relying on brittle fixed cell row indices.

Why it matters: Future-proofs the parser against random Irish government formatting shifts and newly added preamble rows.
Step 04 Express.js API

Indexed JSON Cache & REST Endpoints

Transforms parsed records into an indexed cache and exposes modular endpoints: /api/status, /api/search?q=..., and /api/sync for manual triggers.

Why it matters: Enables sub-millisecond case-insensitive query lookups without database bottlenecks.
Step 05 node-cron + UptimeRobot

Scheduled Automation & Keep-Alive

Runs an automated cron job every day at 11:00 AM IST (matching embassy release times). Configured with a 5-minute UptimeRobot heartbeat ping.

Why it matters: Bypasses Render free-tier container sleep constraints, ensuring 24/7 background cron reliability.
Step 06 Vanilla JS & CSS

Glassmorphic UI & Client Validation

Features strict 8-digit client-side input validation, animated Celtic clover state transitions, and responsive status alert cards.

Why it matters: Saves server bandwidth by preventing malformed requests and delivers an empathetic, stress-reducing user experience.

System Architecture Highlights

  • Resilient Scraping & Parsing Engine: Uses Cheerio and SheetJS (xlsx) with heuristic column mapping to ingest complex OpenDocument formats seamlessly.
  • Container Persistence Architecture: Solved cloud container suspension via UptimeRobot automated polling, maintaining scheduled daily updates without dedicated infrastructure costs.
  • Lightweight REST Microservice: Express.js backend serving both API consumers and the frontend single-page dashboard with zero heavy framework bloat.
  • Empathetic UX Design: Instant status categorization (Approved in emerald green, Refused in alert red, Pending in informative amber) providing clarity for nervous visa applicants.
